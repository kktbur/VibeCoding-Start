# Project Instructions

This file contains the project's local instructions for AI and human contributors.

## First read

Read `docs/INDEX.md`, `docs/CURRENT.md`, `docs/PRODUCT.md`, `docs/PRD.md`, and `docs/ACCEPTANCE.md` before substantive work. Read `docs/CODEMAP.md` and warm records when needed.

## Local memory

Keep raw sessions, evidence, failed attempts, investigations, logs, and test artifacts in `.project-memory/`. Do not commit secrets, tokens, cookies, private keys, or unredacted personal data. Curate durable facts into `docs/` and publish only redacted reusable examples.

## Working rules

- Preserve existing valid knowledge and update the relevant index when structure changes.
- Follow the project's active PRD and acceptance criteria.
- Use existing capabilities before building new general infrastructure.
- Record material decisions and run the relevant deterministic checks before claiming completion.
