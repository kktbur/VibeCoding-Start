# Local Project Memory

This directory stores raw sessions, command output, investigations, failed attempts, evidence, and test artifacts for local development.

Raw memory is intentionally local by default:

- `.gitignore` ignores everything here except this boundary note.
- Do not put API keys, tokens, cookies, private keys, passwords, or unnecessary personal data into raw records.
- Preserve raw history locally; curate durable facts into `docs/`.
- Promote only redacted, intentionally reusable examples to `docs/examples/`.

The public repository contains the policy and examples, not this project's private raw session history.
