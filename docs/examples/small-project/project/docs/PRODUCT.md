# Product Definition

## Problem

Renaming many local files by hand is repetitive and makes consistent naming difficult.

## Users and owner

- User: one person managing files on a local computer.
- Owner: the person who accepts the naming rules and reviews the result.

## Desired outcome

Provide a small local tool that previews deterministic filename changes before applying them.

## Scope

- Read a user-selected local directory.
- Preview old and new names.
- Apply changes only after explicit owner confirmation.

## Non-goals

- No cloud upload, remote file access, account integration, or automatic destructive cleanup.
- No claim that this redacted example includes an implementation.
