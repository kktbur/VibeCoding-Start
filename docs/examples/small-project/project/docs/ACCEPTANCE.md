# Acceptance Criteria

## Requirement coverage

- REQ-001: Preview is shown before any rename operation.
- REQ-002: No file changes occur without explicit confirmation.
- REQ-003: A file outside the selected directory remains unchanged.
- REQ-004: Conflicts and invalid names are reported and do not produce a silent partial rename.

## Owner checks

- [ ] The owner can understand the preview before confirming.
- [ ] The owner can stop without changing files.
- [ ] The owner can identify how to recover from an accepted rename.

This is a pre-implementation example. The unchecked owner checks are intentional and must not be reported as passed until an implementation exists.
