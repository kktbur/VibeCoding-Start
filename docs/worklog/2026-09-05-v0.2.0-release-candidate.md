## Scope

Continue the original v0.2.0 usability plan after M2 was merged. This session adds the Small-project gate-depth contract and makes the cross-reference boundary explicit and testable before preparing the package version. It does not claim external user feedback and does not add runtime infrastructure.

## Decisions

- Keep the main `vibecoding-start` Skill as the owner of G0-G9 and put the normative gate-depth matrix there.
- Keep `vibecoding-project-knowledge` as the owner of `INIT`, `UPDATE`, and `AUDIT`; put concrete artifact minimums in its `scaling-rules.md` reference.
- Keep the public README pinned to `v0.1.1` until a `v0.2.0` tag actually exists.
- Keep `v0.1.1` frozen as the last-known-good rollback package.

## Implementation

- Added the Small/Medium/Large matrix and Small-project hard constraints to the main Skill.
- Expanded `scaling-rules.md` with concrete Small-project artifact minimums and practical depth guidance.
- Added explicit, testable cross-references between the main Skill, companion Skill, scaling reference, active standard, and README.
- Added `tests/test_small_path_contract.py` and wired it into Plugin Validation CI.
- Added ADR-0006, updated PRD/acceptance/current/index documents, and prepared Plugin version `0.2.0` with a dated changelog entry.
