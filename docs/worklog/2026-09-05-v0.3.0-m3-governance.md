## Decisions

- Keep `standard-v1.3.md` as the only normative standard source; the Chinese README is user-facing and explicitly points to the English standard.
- Use repository-local Markdown community health files instead of adding an App, MCP server, runtime orchestrator, or issue automation.
- Document the exact PowerShell 7 checks and add a small `scripts/check.sh` wrapper for Unix-like shells; the wrapper calls only the repository's standard-library checks.
- Do not require a CLA and do not invent a maintainer email address for security reports.
- Defer the optional standard filename migration to a separate PR.
