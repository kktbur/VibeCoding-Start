# Plan 005: VibeCoding Start v0.2.0 M2 Small-Project Path

- Status: COMPLETED — M2 foundation merged; release-candidate closeout continues under [Plan 006](006-v0.2.0-release-candidate.md)
- Date: 2026-09-05
- Baseline: [v0.1.1 GitHub Release](https://github.com/kktbur/VibeCoding-Start/releases/tag/v0.1.1)
- Trigger: The owner explicitly requested continuation; this plan does not claim external user feedback.

## Goal

Make the first small-project experience easier to understand and hand off while keeping the package Skill-only, local-first, and free of new infrastructure.

## Work packages

- WP-20: provide an English-first, Chinese-second README with stable language anchors and a pinned `v0.1.1` installation path.
- WP-21: publish a compact, fully redacted small-project example that shows the six-document skeleton without pretending to be a production application.
- WP-22: publish Cross-Agent usage notes covering read order, handoff fields, change protocol, and the raw-memory boundary.
- WP-23: add deterministic checks for the public example and include them in the existing Plugin validation workflow.

## Acceptance

- README language links navigate to the English and Chinese sections on GitHub.
- English content appears before the Chinese content, and both sections preserve exact Skill names and commands.
- The pinned installation command resolves to the existing `v0.1.1` tag.
- The README navigation and pinned/development installation paths pass a deterministic contract test.
- The small-project example contains `AGENTS.md`, `INDEX`, `PRODUCT`, `PRD`, `ACCEPTANCE`, `CURRENT`, and `CODEMAP` with no secrets or real user data.
- Cross-Agent notes define a repository-local handoff without introducing an MCP/App service or hidden-memory claim.
- Deterministic tests, document audit, link audit, freshness, package validation, name/version/line-ending checks, and compilation pass.

## Explicit non-goals

Do not add a runtime agent orchestrator, message bus, task queue, vector store, MCP/App dependency, Docker test, clean-room matrix, or release automation in this milestone. Do not change the frozen `v0.1.1` tag.

## Release and rollback

M2 is developed after the released `v0.1.1` baseline and is a candidate for `v0.2.0` only after acceptance. Roll back by reverting the M2 documentation and validation commits; retain `v0.1.1` as the last released package.

## Result

WP-20 through WP-23 were implemented, independently reviewed, validated locally, and merged through [PR #4](https://github.com/kktbur/VibeCoding-Start/pull/4). The public `main` README now exposes visible English/Chinese language controls, the small-project example and Cross-Agent contract are public, and post-merge Plugin Validation and Standards Audit both pass. The owner then authorized continuation after the rendered README correction.

The remaining original-roadmap work before the `v0.2.0` tag—explicit Small/Medium/Large gate depth and the final cross-reference review—is tracked in Plan 006 so the foundation history remains stable and auditable.
