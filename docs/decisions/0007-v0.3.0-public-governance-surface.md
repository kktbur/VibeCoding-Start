# ADR-0007: v0.3.0 Public Governance Surface

- Status: ACCEPTED
- Date: 2026-09-05
- Scope: v0.3.0 ecosystem and governance release

## Context

The published `v0.2.0` package makes the workflow and Small-project path visible, but contributors and Chinese-speaking users still lack a dedicated entry point for user-facing Chinese guidance, contribution expectations, and security reporting. GitHub supports repository-local community health files, so these entry points can remain plain Markdown without adding a runtime dependency.

## Decision

- Add `README.zh-CN.md` as a user-facing Chinese mirror for Why, installation, privacy, examples, contribution links, and license guidance.
- Keep the English README first and keep the English `standard-v1.3.md` as the single normative standard. Do not maintain a full translated copy of the standard in this milestone.
- Put contributor and security entry points at the repository root, with Issue templates under `.github/ISSUE_TEMPLATE/` and the PR template at `.github/PULL_REQUEST_TEMPLATE.md`.
- Document the exact PowerShell 7 checks and provide a small `scripts/check.sh` wrapper for Unix-like shells; the wrapper must call only the repository's standard-library checks.
- Do not require a CLA. Ask for small, traceable changes, independent review of important Skill wording, exact verification evidence, and a rollback method.
- Tell contributors not to paste raw `.project-memory` records or secrets into public Issues and PRs. Security reports use a private route when available; no maintainer email is invented.
- Defer the optional standard filename migration to a separate PR so it cannot be mixed with governance content or standard-body changes.

## Consequences

Users get a visible language switch and a stable v0.3.0 installation pin. Contributors get a consistent place to find checks and PR expectations. Maintainers receive safer issue intake without adding an orchestrator or service. The repository intentionally has two user-facing README files but only one normative engineering standard.
